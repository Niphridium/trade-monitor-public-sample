# Data and privacy

This is a public, synthetic demonstration.

- All 96 candles are generated by a deterministic pseudo-random function with fixed illustrative events. No exchange response was used.
- The symbol `DEMO/USDT`, event identifiers and values are fictitious.
- There are no customer records, employer materials, account identifiers, actual investigations, API keys, credentials, logs or production database files.
- The full application and its working database are not part of this repository.
- Interactions run locally in the browser. The sample does not send its generated values or selections to a server and does not save them between visits.
- Evidence download creates a local JSON file containing only this generated fixture and its calculations.
- No application analytics, cookies, advertising, external fonts or third-party scripts are used. The hosting provider may receive normal web request information such as IP address and user agent.
- The GitHub links are ordinary outbound links. Clicking them opens GitHub.

This sample explains calculations and a review workflow. It makes no claim of detection accuracy, identification of a trader, proof of intent, regulatory certification or affiliation with another vendor.
